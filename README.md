<!-- ═══════════════════ SETUP ═══════════════════ -->
<details>
<summary><b>⚙️ &nbsp;Setup — run these two workflows once</b></summary>

<br/>

**1. Create a token** — GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic). Scopes: `read:user` and `repo`. Save it in this repo as a secret named `METRICS_TOKEN` (Settings → Secrets and variables → Actions).

**2. Add two workflows** to `.github/workflows/` in this repo:

| File | What it generates |
| --- | --- |
| `metrics.yml` | `metrics/overview.svg`, `languages.svg`, `calendar.svg`, `habits.svg`, `achievements.svg` |
| `snake.yml` | `github-snake.svg` and `github-snake-dark.svg` on an `output` branch |

**3. Run both once** from the Actions tab (`Run workflow`). After the first successful run, every card above starts rendering. `metrics.yml` refreshes every 8 hours, `snake.yml` every 12.

Why this setup: all cards are committed into this repository and served from `raw.githubusercontent.com`, so they do not break when a free third-party renderer is rate-limited or paused.

**4. Notes**

- If this repo's default branch is `master` rather than `main`, change `main` to `master` in the image URLs and in the workflow triggers.
- `config_timezone: Asia/Kolkata` in `metrics.yml` controls the habits chart — change it if you're elsewhere.
- Cards live in `metrics/`. To restyle, add `template: classic` plus `config_display: large` or a `base_indepth` option; the full plugin list is in the [metrics documentation](https://github.com/lowlighter/metrics#-documentation).
- GitHub proxies README images through `camo.githubusercontent.com` and caches them, so a freshly generated card can take a few minutes to appear. A hard refresh usually does it.
- Discord is a display badge, not a link — `discord.gg/Rishabh#9341` is a username, not an invite. Swap in a real invite URL if you have a server.
- The divider and footer GIFs come from `user-images.githubusercontent.com`; the badges come from `shields.io`, `skillicons.dev`, `komarev.com`, and `capsule-render.vercel.app`. Those are static or cheap enough to stay reliable.

</details>
