<summary><b>⚙️ &nbsp;Setup notes — how to make every animation work</b></summary>

<br/>

**1. Contribution snake** — create `.github/workflows/snake.yml` in your `rishabhvyass/rishabhvyass` profile repo:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk@v3
        id: snake-gif
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Run it once from the Actions tab, and the snake will start rendering.

**2. Fixed from the old README**

- Streak stats moved from `github-readme-streak-stats.herokuapp.com` (offline since Heroku killed free dynos) to `streak-stats.demolab.com`.
- Typing SVG uses `readme-typing-svg.demolab.com` — the maintained domain.
- Every "Languages and Tools" icon previously linked to `developer.mozilla.org/en-US/docs/Web/<tool>`, which 404s for AWS, Docker, React, etc. Icons are now grouped, unlinked, and deduplicated (React Native no longer renders a duplicate React icon).
- Discord badge is now a display badge instead of a broken `discord.gg/Rishabh#9341` invite — replace it with a real invite URL if you have a server.

**3. Optional extras**

- `include_all_commits=true` and `count_private=true` make the stats card heavier; if it ever shows "Maximum retries exceeded", [self-host github-readme-stats on Vercel](https://github.com/anuraghazra/github-readme-stats#deploy-on-your-own-vercel-instance) and swap the domain.
- Swap `theme=tokyonight` for `radical`, `dracula`, `catppuccin_mocha`, or `transparent` to restyle every card at once.
- The GIFs come from `user-images.githubusercontent.com` and `giphy.com` — third-party assets. Preview the rendered README once on GitHub and replace any broken image URL.
